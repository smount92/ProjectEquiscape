# The Big Push — Go-Live Runbook (August 2026)

Everything below assumes the final wave (threads polish, passport polish,
Members room, market completion) has merged and gated. Nothing here is
time-critical; do it in order at your own pace.

## 1. Pre-flight (owner, ~10 min)

- [ ] Walk the dev server (localhost:3939) logged in, light AND Lamplight:
      The Paddock (door + strip + rail + composer), a barn page, an event,
      /market + /market/guide, a public passport, /discover (Members).
- [ ] Walk it logged OUT (InPrivate): /market browse, a passport, /shows.
- [ ] Anything that looks off → tell Claude before pushing.

## 2. Ship

- [ ] Approve the push (Claude pushes the batch to origin/main → Vercel
      deploys automatically).
- [ ] Watch the Vercel build go green.

no redeploy needed.
