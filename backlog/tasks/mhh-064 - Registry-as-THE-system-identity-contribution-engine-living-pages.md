## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
**Why**
The Registry is the reason members come. Owner's big-picture plan, three phases, no rewrite.

**Source**
Old Roadmap goal (owner, big-picture session 2026-10-12).

**Notes**
Phase 1 foundation: permanent registry numbers that survive merges, alias names, a unique identity key (maker + scale + generation + title) so the database refuses duplicates, generation/series as real fields, release pieces so sets list every mold, scale inherited from the mold, search covering aliases, model numbers, colours and mold names.
Phase 2 contribution engine: typed proposals, guided add-a-release with a mold picker, spreadsheet batches, stewards per area (see the Registry moderator design ticket), auto-apply with revert.
Phase 3 living registry: real examples from member stables, ownership counts, price history and show results on release pages, a completeness score and help-wanted queue, public IDs, export and a read API under an open-data licence; NAMHSA horse numbers point at release IDs.
